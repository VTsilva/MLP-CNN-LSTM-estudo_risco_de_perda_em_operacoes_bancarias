# Silver — dados validados para análise

Propósito: disponibilizar uma versão validada e documentada do dataset para EDA e definição de features.

Possíveis ações, somente após validação: seleção de colunas, padronização de nomes, checagens de frequência, regras de tratamento justificadas e criação de tabelas analíticas.

Não aplicar imputação, remoção de outliers, diferenciação ou outros tratamentos sem evidência e justificativa. Ainda não existe dataset Silver gerado.
